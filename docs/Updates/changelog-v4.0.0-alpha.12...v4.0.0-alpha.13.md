## Release notes

### Summary
A ground-up architectural release. The legacy `KeyAsio.Shared` monolith has been decomposed into focused layers (`KeyAsio.Common`, `KeyAsio.Configuration`, `KeyAsio.Application`), and plugins now compile against a single narrow `KeyAsio.Plugins.Contracts` surface that no longer leaks the host's DI container, Avalonia, Suki or Octokit types. The limiter and stereo-balance engines were rebuilt around clearer DSP primitives — a zero-latency `SamplePeakLimiter`, a rational soft-clipper, and a center-preserving `ProMixFocus` sound-field mode replace the older `Master` / `Polynomial` / `Mid-Side` / `CrossMix` options. Audio-device switches are now transactional with automatic rollback, loop SFX pause in place instead of being torn down, and the lazer IPC protocol now carries per-beatmap audio offset so plugins can read the user's local offset.


### Features
- **New plugin contract (`KeyAsio.Plugins.Contracts`)**: A single, intentionally-breaking API surface plugins compile against. `IPluginContext` exposes explicit capabilities (`IAudioEngine`, `IPluginSettings`, `IGameplaySession`, `IPluginInteractionService`, `LoggerFactory`) instead of a root `IServiceProvider`. Host-side adapters (`AudioEngineWrapper`, `GameplaySessionAdapter`, `PluginSettingsAdapter`, `PluginSyncContextAdapter`) bridge the internal services to the contract. `UpdateRelease` / `UpdateAsset` records replace raw `Octokit.Release` so plugins no longer reference Octokit. (`KeyAsio.Plugins.Contracts/*`, `KeyAsio.Application/Plugins/*`, `docs/architecture.md`)
- **ProMix Focus balance mode**: Replaces the old `MidSide` mode as KeyASIO's signature center-preserving sound-field effect. The previous `CrossMix` and `BinauralMix` modes were removed; `ConstantPower` was rewritten as a true equal-power sin/cos pan and a new `LinearStereoPan` mode was added for linear-gain panning. (`BalanceMode.cs`, `ProfessionalBalanceProvider.cs`)
- **SamplePeakLimiter & RationalSoftClipper**: The limiter system was rebuilt. `MasterLimiterProvider` → `SamplePeakLimiter` (zero-delay peak limiter), `PolynomialLimiterProvider` → `RationalSoftClipper` (rational-function soft clip), `HardLimiterProvider` → `HardClipper`; the tanh-based `SoftLimiterProvider` was removed. The `LimiterType` enum now exposes `Off` / `Peak` / `Soft` / `Hard`, with `Peak` as the new default. (`LimiterType.cs`, `SampleProviders/Limiters/*`, `AudioEngine.cs`, `AppSettings.cs`)
- **Beatmap Offset Sync (Lazer IPC)**: The lazer IPC delta-frame protocol now carries `BeatmapOffset`, exposed on `ISyncContext` / `SyncSessionContext` / `GameSyncSnapshot` so plugins can read the user's per-beatmap audio offset. Non-finite values (NaN, infinity) are clamped to 0 on decode. (`LazerIpcFrame.cs`, `ISyncContext.cs`, `GameSyncSnapshot.cs`, `SyncSessionContext.cs`)
- **In-Place Loop Pause/Resume**: `LoopSampleProvider` gains an `IsPaused` flag that zeroes its output while keeping the mixer channel alive (`SignalKeepAlive`); `LoopProviderManager.PauseAll` / `ResumeAll` now pause providers in place instead of removing/re-adding them to the mixer, avoiding recycling churn and channel-id churn during gameplay pauses. (`LoopProvider.cs`, `LoopProviderManager.cs`, `LoopSampleProvider.cs`)
- **Per-Client Skin Selection**: `Paths.SelectedSkinName` was split into `SelectedSkinNameStable` and `SelectedSkinNameLazer`, so the stable and lazer skin dropdowns persist independently. A new `GameClientType` enum records the last-synced client. (`AppSettings.cs`, `GameClientType.cs`, `SkinManager.cs`, `KeyboardBindingInitializer.cs`)
- **Robust Plugin Lifecycle**: `PluginManager` now uses a `NeedsShutdown` flag and `TryShutdownPlugin` to guarantee `Shutdown` is retried on failure (and not double-called on success). Plugin assemblies load into per-plugin collectible `PluginLoadContext`s that share host-owned contract assemblies by type identity while keeping plugin-private dependencies unloadable. (`PluginManager.cs`)

### Enhancements
- **Transactional Audio-Device Coordinator**: New `IAudioDeviceOperationCoordinator` / `AudioDeviceOperationCoordinator` serialize device transitions, start the requested device before persisting settings, and roll back both runtime device and persisted configuration on failure. `AudioSettingsViewModel` and `WizardAudioConfigViewModel` now go through this coordinator instead of mutating the engine and settings directly. (`AudioDeviceOperationCoordinator.cs`, `AudioSettingsViewModel.cs`, `WizardAudioConfigViewModel.cs`)
- **Decoupled Sync ↔ Plugin Layer**: Plugin invocation, state dispatch and exception isolation were extracted from `SyncController` into `SyncPluginCoordinator`, which implements the new `ISyncExtensionHost` port owned by `KeyAsio.Sync`. `KeyAsio.Sync` no longer references `KeyAsio.Application` or the plugin contracts — the dependency is inverted via `AddApplicationModule`. (`SyncController.cs`, `SyncPluginCoordinator.cs`, `ISyncExtensionHost.cs`, `DependencyInjectionExtensions.cs`)
- **Skin Manager as `ISkinResourceProvider`**: `SkinManager` moved to `KeyAsio.Application.Services` and now implements `ISkinResourceProvider`, exposing stable/lazer resource lookups and per-skin beatmap catalogs to the sync layer through the abstraction. (`SkinManager.cs`, `ISkinResourceProvider.cs`)
- **Config Migration**: `MyYamlConfigurationConverter` rewrites legacy enum values on load — `MidSide` → `ProMixFocus`, `BinauralMix` → `LinearStereoPan`, `CrossMix` → `ConstantPower`, `Polynomial` → `Soft` — so existing user configs remain valid. (`MyYamlConfigurationConverter.cs`)
- **Preset Re-mapping**: The "Fast" preset now maps to `Soft` + `ConstantPower`; "Standard" maps to `Peak` + `ProMixFocus`. (`PresetManager.cs`)
- **Keyboard Binding No Longer Drops Inputs on Pause**: `KeyboardBindingInitializer` removed the `IsAudioPaused` guard before `ProcessInteraction`; the pause flag can briefly toggle during normal stable memory timing and must not discard a physical key press. (`KeyboardBindingInitializer.cs`)
- **Refreshed Localization**: Balance-mode labels, limiter descriptions, and the "Stereo Width" → "Pan Strength" / "Narrow·Wide" → "Subtle·Strong" copy were rewritten across English, Simplified Chinese and Japanese to match the new DSP model. (`SR.resx`, `SR.en.resx`, `SR.zh-hans.resx`, `SR.ja.resx`, `SR.Designer.cs`)
- **Flatter App Icon**: The application icon was redesigned in a flatter style; the main-window icon path was corrected back to the 24px asset. (`Assets/KeyAsio.ico`, `Assets/keyasio_32.svg`, `MainWindow.axaml`)

### Fixes
- **Device Release Order on Stop**: `AudioEngine.StopDevice` now calls `DisposeDevice` *before* nulling the limiter and volume sample providers, preventing resource-access errors during shutdown. (`AudioEngine.cs`)
- **Stale Persisted ClientType**: `SkinManager` corrects a stale persisted `ClientType` on startup so a previous lazer session doesn't force lazer skin loading when only stable is running. (`SkinManager.cs`)
- **ProfessionalBalanceProvider Balance Algorithm**: The equal-power and linear-pan gain paths were corrected to use proper sin/cos and linear-transfer laws; the old `AntiClipStrategy` branching (and `PreventiveAttenuation` safety factor) was removed entirely — clipping protection is now owned solely by the final mixer limiter. (`ProfessionalBalanceProvider.cs`, `LoopProvider.cs`)
- **Default Balance Factor**: Lowered the `BalanceFactor` default to `0.2` to match the new pan-strength scaling. (`AppSettings.cs`)

### Miscellaneous
- **Layered Solution Architecture**: The `KeyAsio.Shared` project was removed and its contents redistributed across `KeyAsio.Common` (utils, `AsyncLock`, `AsyncSequentialWorker`, `ObservableRangeCollection`), `KeyAsio.Configuration` (settings + YAML serialization), `KeyAsio.Application` (host runtime, plugins, skin, localization) and `KeyAsio.Sync` (formerly under `KeyAsio.Shared/Sync`). Project boundaries are documented in `docs/architecture.md`.
- **Central Package Management**: Added `Directory.Packages.props` with `ManagePackageVersionsCentrally` and transitive pinning; per-project version attributes were removed. (`Directory.Packages.props`, `dependencies/Directory.Packages.props`, all `*.csproj`)
- **CI Workflow**: Added `.github/workflows/ci.yml` building and testing the solution on `windows-latest` with .NET 10. (`.github/workflows/ci.yml`)
- **EditorConfig**: Added a root `.editorconfig` enforcing final-newline. (`.editorconfig`)
- **New Tests**: `LoopProviderTests`, `AsyncSequentialWorkerTests`, `AudioDeviceOperationCoordinatorTests`, `LazerProtocolTests` (covering `BeatmapOffset`), and `SyncPluginCoordinatorTests`. (`tests/AudioTests/`, `tests/KeyAsio.UnitTests/`)
- **Submodule Update**: `dependencies/osu.Game.Rulesets.KeyAsio` bumped to include the `BeatmapOffset` protocol field. (`dependencies/osu.Game.Rulesets.KeyAsio`)
